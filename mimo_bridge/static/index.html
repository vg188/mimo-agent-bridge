使用教程
从安装到接入 Agent 的完整说明。

      

        
1. 识别登录态

        
首页点「① 一键识别登录态」。若卡在等待：把 MiMo Desktop 关闭 2 秒再打开。成功后左侧「登录态」会变成已登录。

      

      

        
2. 确认套餐

        
打开「套餐用量」，应显示你的套餐名（入门/进阶/高阶/尊享）与有效期。若显示暂无套餐，说明该账号未订阅。

      

      

        
3. 接入 Agent

        
到「接入配置」点「复制 OpenAI 配置」，粘贴到 Cursor / Continue 的 OpenAI Compatible 栏。Claude Code 则复制环境变量。

      

      

        
4. 常见问题

        

          一直显示未登录？ 自动识别时务必关闭 MiMo Desktop 2 秒。

          找不到按钮？ 看左侧「首页向导」/「登录态」，都有大按钮。

          Agent 连不上？ 确认网关已启动（状态卡片为运行中），端口 8787。

          401？ Cookie 过期，重新自动识别。
